\chapter{Шаг 2. Создание архитектуры нейронной сети (Вариант 2)}

\section{Теоретические компоненты архитектуры}

Операция двумерной дискретной свертки входного тензора $I \in \mathbb{R}^{H \times W \times C_{\text{in}}}$ с обучаемым ядром $K \in \mathbb{R}^{k_h \times k_w \times C_{\text{in}}}$ вычисляет взвешенную локальную сумму пикселей:
\begin{equation}
    S(i, j) = \sum_{c=1}^{C_{\text{in}}} \sum_{m=0}^{k_h - 1} \sum_{n=0}^{k_w - 1} I(i + m, j + n, c) K(m, n, c) + b,
    \label{eq:convolution}
\end{equation}
где $b$ --- обучаемое смещение. Сверточные ядра извлекают иерархические пространственные признаки: от элементарных градиентов и линий до целостных текстур и форм лепестков.

После свертки применяется функция активации $\text{ReLU}(x) = \max(0, x)$, устраняющая затухание градиентов в положительной области. Пространственная редукция выполняется операцией $\text{MaxPooling2D}$ с окном $2 \times 2$ и шагом 2, сокращающей размерность карт признаков в 4 раза по площади.

\subsection{Механизм пакетной нормализации (BatchNormalization)}

Для устранения внутреннего ковариационного сдвига (Internal Covariate Shift) на выходе каждого слоя применяется нормализация по мини-батчу $\mathcal{B} = \{x_1, \dots, x_m\}$:
\begin{equation}
    \mu_\mathcal{B} = \frac{1}{m} \sum_{i=1}^m x_i, \qquad \sigma_\mathcal{B}^2 = \frac{1}{m} \sum_{i=1}^m (x_i - \mu_\mathcal{B})^2, \qquad \hat{x}_i = \frac{x_i - \mu_\mathcal{B}}{\sqrt{\sigma_\mathcal{B}^2 + \epsilon}},
    \label{eq:bn}
\end{equation}
где $\epsilon = 10^{-3}$, а итоговый выход слоя определяется с помощью обучаемых параметров масштаба $\gamma$ и сдвига $\beta$:
\begin{equation}
    y_i = \gamma \hat{x}_i + \beta.
    \label{eq:bn_out}
\end{equation}
Пакетная нормализация стабилизирует распределение активаций, сглаживает поверхность функции потерь и предотвращает застревание оптимизатора в локальных плато.

\subsection{Оптимизатор SGD с моментом Нестерова}

Для минимизации кросс-энтропийной функции потерь используется стохастический градиентный спуск (SGD) со скоростью обучения $\eta = 0.015$ и поправкой Нестерова (NAG) с моментом $\beta = 0.9$:
\begin{equation}
    v_t = \beta v_{t-1} + \eta \nabla_\theta \mathcal{L}(\theta_{t-1} - \beta v_{t-1}), \qquad \theta_t = \theta_{t-1} - v_t.
    \label{eq:nesterov}
\end{equation}
Оценка градиента в упреждающей точке шага по инерции устраняет осцилляции в крутых оврагах оптимизационного рельефа.

\section{Программный листинг сборки модели}

В листинге~\ref{lst:model_code} приведен исходный код сборки модели на Keras Functional API:

\begin{lstlisting}[language=Python, caption={Создание и компиляция архитектуры CNN (Вариант 2)}, label={lst:model_code}, basicstyle=\ttfamily\scriptsize]
import tensorflow as tf

def build_cnn_model(img_size=96, num_classes=102):
    inputs = tf.keras.Input(shape=(img_size, img_size, 3), name="input_image")
    # Блок 1: Conv2D(32, 3x3) + BatchNorm + ReLU + MaxPool(2x2)
    x = tf.keras.layers.Conv2D(32, (3, 3), padding="same", use_bias=False)(inputs)
    x = tf.keras.layers.BatchNormalization()(x)
    x = tf.keras.layers.Activation("relu")(x)
    x = tf.keras.layers.MaxPooling2D(pool_size=(2, 2))(x)
    # Блок 2: Conv2D(64, 3x3) + BatchNorm + ReLU + MaxPool(2x2)
    x = tf.keras.layers.Conv2D(64, (3, 3), padding="same", use_bias=False)(x)
    x = tf.keras.layers.BatchNormalization()(x)
    x = tf.keras.layers.Activation("relu")(x)
    x = tf.keras.layers.MaxPooling2D(pool_size=(2, 2))(x)
    # Блок 3: Conv2D(128, 3x3) + BatchNorm + ReLU + MaxPool(2x2)
    x = tf.keras.layers.Conv2D(128, (3, 3), padding="same", use_bias=False)(x)
    x = tf.keras.layers.BatchNormalization()(x)
    x = tf.keras.layers.Activation("relu")(x)
    x = tf.keras.layers.MaxPooling2D(pool_size=(2, 2))(x)
    # Полносвязный классификатор: Dense(256) + BatchNorm + ReLU + Dense(102, Softmax)
    x = tf.keras.layers.Flatten()(x)
    x = tf.keras.layers.Dense(256, use_bias=False)(x)
    x = tf.keras.layers.BatchNormalization()(x)
    x = tf.keras.layers.Activation("relu")(x)
    outputs = tf.keras.layers.Dense(num_classes, activation="softmax")(x)

    model = tf.keras.Model(inputs=inputs, outputs=outputs, name="CNN_Variant2")
    opt = tf.keras.optimizers.SGD(learning_rate=0.015, momentum=0.9, nesterov=True)
    model.compile(optimizer=opt, loss="sparse_categorical_crossentropy",
                  metrics=["accuracy", tf.keras.metrics.SparseTopKCategoricalAccuracy(k=5, name="top5_acc")])
    return model
\end{lstlisting}
