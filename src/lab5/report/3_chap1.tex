\chapter{Подготовка набора данных Oxford Flowers 102 и конвейер данных}

\section{Характеристика набора данных}

В соответствии с индивидуальным вариантом для исследования используется канонический набор данных \textbf{Oxford Flowers 102}, разработанный Отделом инженерии Оксфордского университета для решения задач мелкозернистой визуальной классификации (fine-grained image classification).

Набор содержит $8189$ цветных фотоснимков цветковых растений, произрастающих в Великобритании, разбитых на $102$ таксономические категории (от $40$ до $258$ изображений на класс). Датасет характеризуется высокой внутриклассовой вариативностью (различные стадии цветения, освещение, угол съемки и природный фон) и высокой межклассовой схожестью между близкородственными видами.

Исходная выборка разделена на три фиксированных подмножества:
\begin{enumerate}
    \item \textbf{Обучающая выборка (\texttt{train}):} $1020$ изображений (строго по $10$ примеров на каждый из $102$ классов);
    \item \textbf{Валидационная выборка (\texttt{validation}):} $1020$ изображений (по $10$ примеров на класс) для контроля переобучения;
    \item \textbf{Контрольная тестовая выборка (\texttt{test}):} $6149$ изображений, составляющая свыше $75\,\%$ всех данных для объективной итоговой проверки.
\end{enumerate}

\section{Предобработка, аугментация и конвейер \texttt{tf.data}}

Оригинальные фотографии имеют произвольные геометрические пропорции и пространственные размеры. Для подачи в сверточную сеть реализован стандартизированный конвейер предварительной обработки данных:
\begin{enumerate}
    \item \textbf{Масштабирование геометрии:} приведение каждого кадра к фиксированному разрешению $96 \times 96 \times 3$ методом билинейной интерполяции (\texttt{tf.image.resize}).
    \item \textbf{Нормализация яркости:} преобразование целочисленных значений пикселей из интервала $[0, 255]$ в вещественный диапазон $[0.0, 1.0]$.
    \item \textbf{Потоковая аугментация:} поскольку на обучение каждого класса отведено всего 10 образцов, для предотвращения меморизации и переобучения применен слой аугментации:
    \begin{itemize}
        \item случайное горизонтальное зеркальное отражение (\texttt{RandomFlip("horizontal")});
        \item случайный поворот на угол до $\pm 10\,\%$ (\texttt{RandomRotation(0.1)});
        \item случайное масштабирование до $\pm 8\,\%$ (\texttt{RandomZoom(0.08)}).
    \end{itemize}
    \item \textbf{Оптимизация производительности:} конвейер \texttt{tf.data} включает кэширование тензоров в оперативной памяти (\texttt{cache()}), перемешивание буфера (\texttt{shuffle(1020)}), батчирование (\texttt{batch(32)}) и конвейерную предвыборку данных параллельно с работой процессора (\texttt{prefetch(tf.data.AUTOTUNE)}).
\end{enumerate}
