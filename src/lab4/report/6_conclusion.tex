\chapter*{Заключение}
\addcontentsline{toc}{chapter}{Заключение}

В ходе лабораторной работы выполнен сравнительный анализ классической линейной регрессии, Lasso и ElasticNet при решении задачи прогнозирования рыночной стоимости жилой недвижимости Египта на открытом наборе данных PropertyFinder.

По результатам проведенного исследования сформулированы следующие выводы:
\begin{enumerate}
    \item \textbf{Предобработка признакового пространства:} заполнение пропусков в технических характеристиках объектов робастными статистиками (медиана для числовых параметров, мода для категорий), целочисленное кодирование категориальных атрибутов методом \texttt{LabelEncoder} и стандартизация признаков через \texttt{StandardScaler} обеспечили математическую корректность вычисления регуляризационных штрафов $L_1$ и $L_2$.
    \item \textbf{Базовые регрессионные модели:} классическая линейная регрессия МНК и модель Lasso с параметром по умолчанию показали высокое и стабильное качество на тестовой выборке ($R^2 = 0.8242$, $RMSE \approx 2.441$ млн EGP). В то же время базовый ElasticNet с единичными параметрами ($\alpha = 1.0$, $l_1\text{-ratio} = 0.5$) продемонстрировал выраженную недообученность ($R^2 = 0.6380$) из-за чрезмерного сжатия весов ключевых признаков (площади и локации).
    \item \textbf{Подбор гиперпараметров и валидация:} оптимизация гиперпараметров через \texttt{GridSearchCV} с 5-кратной кросс-валидацией позволила найти оптимальные конфигурации регуляризаторов ($\alpha = 1000.0$ для Lasso и $\alpha = 0.001$, $l_1\text{-ratio} = 0.1$ для ElasticNet). Оптимизация полностью устранила недообучение ElasticNet, подняв коэффициент детерминации до $R^2 = 0.8242$ и сократив тестовую ошибку на 30\%.
    \item \textbf{Практическая применимость:} все три оптимизированные модели достигли одинаково высокой предсказательной точности, однако модели с регуляризацией обладают преимуществом гарантированной устойчивости к коллинеарности признаков и лучшей генерализационной способностью.
\end{enumerate}
