# Лабораторные работы по Машинному Обучению (СибГУТИ)

Репозиторий для выполнения цикла лабораторных работ по дисциплине «Машинное обучение» кафедры Прикладной математики и кибернетики (ПМ и К) СибГУТИ.

- **Группа:** ИП-414
- **Студенты:** Зинаков Михаил Романович, Карев Александр Александрович
- **Преподаватель:** старший преподаватель каф. ПМ и К Дементьева К. И.

## Стек технологий и стандарты

- **Менеджер пакетов и окружения:** [uv](https://docs.astral.sh/uv/) (виртуальное окружение Python 3.12).
- **Стиль и линтинг:** [ruff](https://docs.astral.sh/ruff/) (единый стиль кода, автоформатирование).
- **Git-хуки:** [prek](https://github.com/j178/prek) (автоматический запуск ruff и проверка Conventional Commits).
- **Менеджер задач:** [just](https://github.com/casey/just).

## Структура репозитория

```
machine_learning/
├── .gitignore
├── .pre-commit-config.yaml
├── pyproject.toml
├── justfile                       # Корневой justfile для общих команд
├── README.md
├── assignments/                   # Методические материалы и задания
├── resources/                     # Шаблоны отчетов и стилистические руководства
└── src/
    └── lab4/                      # Лабораторная работа №4 (Сравнительный анализ методов регрессии)
        ├── justfile               # Локальный justfile лабы 4
        ├── lab4.ipynb             # Интерактивный блокнот с кодом, графиками и выводами
        ├── data/                  # Датасет
        └── report/                # Академический LaTeX-отчет
```

## Быстрый старт

1. **Установка зависимостей и хуков:**
   ```bash
   just setup
   ```
2. **Проверка стиля и линтера:**
   ```bash
   just check
   ```
3. **Запуск лабораторной работы №4 в Jupyter:**
   ```bash
   just lab4 notebook
   ```
4. **Сквозное тестирование блокнота лабораторной работы №4:**
   ```bash
   just lab4 test
   ```
5. **Сборка PDF-отчета лабораторной работы №4:**
   ```bash
   just lab4 report
   ```
